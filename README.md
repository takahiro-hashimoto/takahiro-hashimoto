# タカヒロ / Takahiro

ガジェット・中古デバイス・夜景写真など、さまざまなテーマのWebサイトを企画・開発・運営しています。

運営サイトは、ガジェットレビューブログ「デジスタ」、中古デバイスの比較メディア「ユーズドラボ」、夜景スポットを紹介する「東京夜景ナビ」。それぞれのテーマに合わせ、実体験や独自のデータをもとに情報を発信しています。

Webデザイン・フロントエンド開発・Webディレクション・プロジェクトマネジメントの経験を活かし、サイトの設計・実装から記事執筆、写真・動画撮影まで一貫して手がけています。Webサイトの運営を通じて、情報をわかりやすく届けることと、目的に合った情報を探せる仕組みづくりに取り組んでいます。

## [デジスタ(https://digital-style.jp/)

2015年12月に開設した個人メディア。ガジェットやApple製品の周辺機器、デスク周り、インテリア・生活雑貨などを紹介しています。

記事執筆から写真・動画撮影まで一人で担当し、これまでに300以上の商品を紹介。「本当に使いたい商品のみを掲載する」「デメリットも正直に書く」を大切にしています。

### 主な活動・実績

- ITmedia「Fav-Log」、レバテック、男の隠れ家での連載
- Ameba Choice、Picky’s、ライフハッカーでの記事監修
- GoodsPressでのインタビュー掲載
- バリューコマース メディアアワード2022年上期 総合賞3位・カテゴリー賞を受賞
- A8.net エーハチレビュー部 2022年7月レビューコンテスト ブログ賞を受賞

詳しい掲載歴・レビュー実績は、[デジスタの運営者情報](https://digital-style.jp/about)にまとめています。

## [ユーズドラボ](https://used-lab.jp/)

中古・型落ちのiPhone、Androidスマホ、iPad、Mac、Apple Watchなどの選び方を紹介するメディアです。エンジニアの知見を活かし、中古相場・価格推移の比較や、予算・用途に合わせた機種診断ツールを開発・実装しています。

### 主な活動・取り組み

- 2024年8月にサイトを開設
- 中古デバイスの相場・価格推移を比較できるコンテンツを開発・運営
- 予算や用途から選べる機種診断ツールを開発・実装
- スペック・サポート期間・購入前の注意点を整理し、買い替え判断をサポート

運営者は2011年のiPhone 4sからApple製品を継続して購入し、その経験をコンテンツ制作に活かしています。連載・監修・受賞などの運営者実績は、[ユーズドラボの運営者情報](https://used-lab.jp/profile/)に掲載しています。

## [東京夜景ナビ](https://nightscape.tokyo/)

自ら訪問・撮影した夜景スポットを写真とともに紹介する専門メディアです。定番から穴場まで、デート・旅行・写真撮影に合う場所を探せます。写真・映像の企業広告やテレビ番組への提供、撮影の仕事にも取り組んでいます。

### 主な活動・実績

- 東京タワー公式サイトのPC版トップページ用タイムラプス映像を撮影
- ザ・プリンス パークタワー東京の客室・レストランの写真・映像、20周年リニューアルの室内写真を撮影
- 名古屋プリンスホテル スカイタワーの客室からの眺望写真・映像を撮影
- 日本電設工業のWebサイト用タイムラプス映像を提供
- NHK総合、BS-TBS、テレビ朝日の番組に写真・映像を提供
- 動画コンテスト「港、動く 15秒の物語」の審査員を担当
- 第8回東京大回廊写真コンテスト 出光美術館賞を受賞
- 朝日新聞のコラムにインタビュー掲載

詳しい撮影・素材提供・受賞歴は、[東京夜景ナビの運営者情報](https://nightscape.tokyo/about/)にまとめています。
